# 一瞥 · Glimpse

给闲暇，留一点诗意。电脑闲置时，以诗画作屏保；想读时，也可以打开一瞥。

## 1.0.1 公开测试版

[下载 Mac 通用安装包](https://github.com/ActivationEnergy/Glimpse/raw/refs/tags/v1.0.1/Releases/v1.0.1/Glimpse-1.0.1-macOS-universal.dmg)

适用于 macOS 14 及以上，支持 Apple Silicon 与 Intel。包含 1,105 篇目录作品、24 组核心配景；两组扩展默认不下载。

```sh
brew install --cask activationenergy/tap/glimpse
```

本次公开测试包采用临时签名，尚未完成 Apple 公证。请阅读[安装说明](Releases/v1.0.1/安装说明.txt)。App 与屏保需分别更新。

本版修复主 App 目录仅显示 140 篇、首次下载扩展配景权限、屏保未绘制即记入历史、失效屏保记录导航及组件版本不一致的问题。

安装包按固定版本标签保存，是 Git 仓库版本文件，并非 GitHub Release 附件。网站成品位于 `docs/`，供 GitHub Pages 发布；源码、开发历史和编辑资料不公开。
